## Project Objective

The objective of this project is to build a Machine Learning model that can classify Iris flowers into three species:

- Setosa
- Versicolor
- Virginica

based on their flower measurements.

---

## Dataset

The project uses the famous Iris Dataset containing:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species (Target Variable)

Total Records: 150
